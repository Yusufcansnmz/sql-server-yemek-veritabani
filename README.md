# SQL Server Yemek Veritabanı

Bu proje, SQL Server kullanılarak oluşturulmuş bir yemek tarifleri
veritabanı projesidir.

## İçerik

- Yemekler
- Yemek türleri
- Malzemeler
- Yemek-Malzeme ilişkileri
- Kullanıcılar
- Yorumlar
- Puanlar
- Favoriler

## Kullanılan Teknolojiler

- Microsoft SQL Server
- SQL
- SQL Server Management Studio (SSMS)

## Veritabanı Özellikleri

- Primary Key / Foreign Key
- JOIN işlemleri
- GROUP BY
- Aggregate Functions
- VIEW
- CHECK Constraint
- UNIQUE Constraint
- IDENTITY

## Yedek

`Yemek.bak` dosyası, SQL Server veritabanının yedeğidir.
